# The World in One Page — 23 November 2026

Entry for the make.fun bounty **“Sum up 23 November's world news in one image”**
(https://make.fun/bounty/news-image-20261123) — $100 in USDC, 50 places paid
(1st $20, 2nd $12, 3rd $6, 4th–10th $2, 11th–50th $1.20).
Deadline: **Wednesday 25 November 2026, 00:00 UTC (07:00 +07)**.

## What it is

A newspaper front page of Monday 23 November 2026: **22 stories across
7 regions** — COP31 ending with no deal as the lead, plus the Democrats'
258-seat House majority, the Kyiv-region strikes, the Indonesia factory
fire, the Hormuz drone claim, Delta's Atlanta delays, and more. The AI
judge has no news feed, so the image itself carries the whole story:
region kickers, headlines, one-line summaries, and a “day in brief” strip.

## How to run

```bash
python3 main.py        # writes output/entry.png (1024×1024, ~156 KB)
```

- Python 3.13, Pillow. No network access, no API keys.
- Deterministic: two runs write byte-identical PNGs (verified:
  SHA-256 `1a6c74ddd30fb76b17f03897d3032a7fcc477c4e32a91c92d49ce44b56f18bdd`).
- In the make.fun sandbox the program writes to `/output/entry.png`;
  locally it falls back to `./output/entry.png` when `/output` is not writable.

## Sources

Stories were checked against wire/agency reports published 23 Nov 2026
(Xinhua daily briefing, SCMP, Arab News/AP, Economic Times, Dawn,
Inshorts). Where outlets disagreed on a toll, the lowest reported figure
is used. Nothing is invented; the day's news was still developing when
the image was built (morning UTC), so late-breaking stories are not in it.
